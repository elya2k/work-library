# project — рабочая библиотека

Центральное хранилище всех проектов и наработок: Битрикс, клиентские проекты, заметки, шаблоны.

## Структура

```
work-library/  (на компьютере — папка project на рабочем столе)
├── bitrix/          # Всё по 1С-Битрикс / Битрикс24
│   ├── api/         # REST API, вебхуки, примеры вызовов
│   ├── snippets/    # Готовые куски кода (PHP, JS, D7, компоненты)
│   ├── modules/     # Собственные модули и компоненты
│   └── docs/        # Конспекты документации, инструкции, решения проблем
├── projects/        # Отдельные проекты — каждый в своей папке: projects/<имя-проекта>/
├── notes/           # Заметки, идеи, решения, журнал работ
└── templates/       # Шаблоны: ТЗ, договоры, структуры проектов, чек-листы
```

## Правила

- Каждый новый проект — отдельная папка в `projects/` со своим `README.md` (цель, стек, доступы без паролей, статус).
- Повторно используемый код по Битриксу — в `bitrix/snippets/` или `bitrix/modules/`.
- Пароли, токены и ключи вебхуков **не хранить** в репозитории.
