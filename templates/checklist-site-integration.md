## 1. Сбор информации и доступы
- [ ] Адрес сайта, на чём сделан (Тильда, WordPress, 1С-Битрикс, самопис и т.д.)
- [ ] Доступ к админке сайта или контакт разработчика сайта
- [ ] Доступ к порталу Б24 с правами администратора
- [ ] Список всех форм на сайте (заявка, обратный звонок, расчёт, подписка, квиз) — где стоят и какие поля
- [ ] Куда сейчас уходят заявки (почта, телеграм, таблица) и нужно ли это сохранить
- [ ] Какие каналы есть: телефон, WhatsApp, Telegram, онлайн-чат, e-mail
- [ ] Есть ли Яндекс Метрика / Google Analytics, доступы к ним
- [ ] Кто ответственный за заявки с сайта, как распределять между менеджерами

## 2. Подготовка CRM
- [ ] Режим CRM определён: с лидами или простой (сразу сделки)
- [ ] Воронка и стадии для заявок с сайта настроены
- [ ] Источники созданы: «Сайт — форма», «Сайт — чат», «Сайт — звонок» и т.п.
- [ ] Нужные пользовательские поля созданы (услуга, город, бюджет и пр.)
- [ ] Поля для UTM-меток видны в карточке (utm_source, utm_medium, utm_campaign, utm_content, utm_term)
- [ ] Правила распределения / очередь ответственных настроены
- [ ] Контроль дублей включён (по телефону и e-mail)

## 3. Формы
- [ ] Выбран способ: CRM-формы Б24 на сайте / интеграция штатных форм сайта (модуль, вебхук, приложение)
- [ ] Для каждой формы: поля сайта сопоставлены с полями CRM
- [ ] Для каждой формы указан свой источник и ответственный
- [ ] Обязательные поля и маска телефона работают
- [ ] Галочка согласия на обработку персональных данных + ссылка на политику
- [ ] Текст после отправки / редирект на страницу «Спасибо»
- [ ] UTM-метки и страница, с которой отправлена заявка, передаются в CRM
- [ ] Защита от спама (капча / скрытое поле)
- [ ] Старая отправка на почту оставлена или отключена — по согласованию с клиентом

## 4. Виджет и онлайн-чат
- [ ] Открытая линия создана, операторы назначены, график работы задан
- [ ] Виджет сайта настроен: каналы (чат, WhatsApp, Telegram, звонок), цвета, позиция
- [ ] Код виджета установлен на все страницы сайта
- [ ] Приветствие и автоответ в нерабочее время
- [ ] Оценка качества включена/отключена — по согласованию
- [ ] Обращения из чата создают лид/сделку по правилам
- [ ] Виджет не перекрывает кнопки сайта на мобильном

## 5. Телефония и обратный звонок (если есть)
- [ ] Номер подключён к Б24 (SIP / приложение оператора)
- [ ] Номер на сайте совпадает с подключённым
- [ ] Обратный звонок из формы/виджета работает
- [ ] Запись разговоров включена, звонки создают сущности в CRM
- [ ] Коллтрекинг (подменные номера) — если нужен

## 6. Аналитика
- [ ] Сквозная аналитика Б24 подключена (код на сайте, рекламные кабинеты)
- [ ] Яндекс Метрика связана, цели на отправку форм созданы
- [ ] Рекламные ссылки размечены UTM-метками
- [ ] Отчёт по источникам заявок проверен на тестовых данных

## 7. Автоматизация
- [ ] Уведомление ответственному о новой заявке
- [ ] Задача «Связаться с клиентом» с дедлайном
- [ ] Автоматическое письмо/сообщение клиенту «Заявка получена» — по согласованию
- [ ] Напоминание / смена ответственного, если заявку долго не обработали

## 8. Тестирование
- [ ] Каждая форма отправлена с компьютера и с телефона
- [ ] Заявки пришли в CRM с правильными полями, источником, ответственным
- [ ] UTM-метки подтянулись (тест по ссылке с метками)
- [ ] Дубль по тому же телефону обработался правильно
- [ ] Сообщение в чат, WhatsApp, Telegram дошло до оператора, ответ дошёл клиенту
- [ ] Звонок / обратный звонок прошёл и записался
- [ ] Уведомления и задачи создались
- [ ] Цели в Метрике сработали
- [ ] Тестовые лиды/сделки удалены после проверки

## 9. Сдача клиенту
- [ ] Короткое обучение менеджеров: где заявки, как брать в работу, как отвечать в чате
- [ ] Инструкция / запись экрана передана
- [ ] Список того, что сделано, и что осталось на стороне клиента
- [ ] Доступы, выданные на время работ, закрыты или переданы
- [ ] Через 3–7 дней: проверить, что заявки идут, ничего не потерялось
- [ ] Акт / подтверждение от клиента
