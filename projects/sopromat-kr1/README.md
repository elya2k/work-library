# Сопромат — КР №1 «Расчёт при растяжении-сжатии» (схема 2, вариант 5)

**Цель:** построить эпюру продольных сил и подобрать размер сечения «a» ступенчатого стального бруса.

**Дано:** b = 150, c = 140, d = 230 мм; P1 = 50, P2 = 110, P3 = 80 кН; F1 = a × 1,5a; [σ] = 160 МПа.
Площадь F2 не задана — участок b в подборе сечения не участвует.

**Результат:**
- R = 80 кН; N_I = −80 кН (сжатие), N_II = +30 кН (растяжение), N_III = −50 кН (сжатие)
- A_тр = 312,5 мм², a ≥ 14,43 мм → **a = 15 мм** (σ_max = 148,1 МПа ≤ 160 МПа)
