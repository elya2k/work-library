# Almiz (almiz.kz)

Сайт производителя фасадных кассет, металлоконструкций и монтажа фасадов (Алматы).

## Файлы
- `edits/almiz-site-edits.pdf` — итоговые правки для сайта (оформленный PDF, 8 стр.).
- `edits/almiz-site-edits.html` — исходник PDF. Пересборка:
  `chrome --headless --no-pdf-header-footer --print-to-pdf=almiz-site-edits.pdf almiz-site-edits.html`
- `edits/fonts/`, `edits/fonts.css` — шрифты Manrope и Unbounded (OFL), локально для сборки.

## Статус
Правки переданы на внесение. Ожидается от клиента: логотипы и список остальных клиентов,
объём участия по каждому объекту, фото готового фасада школы.
