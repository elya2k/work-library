# Внедрение Битрикс24 CRM — продажа мототехники

**Цель:** базовое внедрение CRM для компании по продаже мототехники, мотоаксессуаров и квадроциклов.
**Стек:** Битрикс24 (облако) + телефония через SIP-коннектор + WhatsApp через Wazzup.
**Статус:** ТЗ v1.0 — черновик для согласования с клиентом.

Полное ТЗ (обложка, разделы по направлениям, воронка со схемой, роботы, приёмка; без этапов и сроков) — в Claude Docs:

## Кратко
- CRM без лидов: обращение сразу создаёт сделку + контакт.
- Воронка одна — «Продажа мототехники» (9 стадий: Новая заявка → Контакт → Выявление потребности → Подбор/КП → Визит/тест-драйв → Кредит/рассрочка → Предоплата/бронь → Подготовка к выдаче → Выдача); аксессуары идут по ней же, пропуская тест-драйв и кредит.
- Поля: категория техники, марка/модель, бюджет, способ оплаты, трейд-ин, тест-драйв, VIN, предоплата, дата выдачи, причина отказа.
- Телефония: SIP-коннектор, очередь «Продажи», запись, пропущенный → дело «Перезвонить» 15 мин.
- WhatsApp: Wazzup (QR или WABA), источник «WhatsApp», быстрые ответы, автоответ.
- Роботы: до 15 (скорость реакции, напоминания, дело «Предложить экипировку» через 7 дней, ТО через 30 дней, возврат отказников).

## Доступы
Не хранить здесь. SIP-данные и доступ к порталу — только в менеджере паролей.
