# Инструкции для Claude

Этот репозиторий — основная рабочая библиотека пользователя («мозг»).
На компьютере пользователя он лежит в папке `project` на рабочем столе.
Все новые проекты, наработки и материалы по Битриксу сохраняй сюда, по структуре из `README.md`:

- Битрикс (REST API, сниппеты, модули, документация) → `bitrix/...`
- Новый проект → `projects/<имя-проекта>/` с собственным `README.md`
- Заметки и журнал работ → `notes/`
- Шаблоны → `templates/`

Никогда не коммить пароли, токены и URL вебхуков с ключами.
