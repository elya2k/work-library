# Подключение SIP-телефонии Tele2 (Казахстан) к Битрикс24

Tele2 KZ выдаёт «SIP-телефонию с динамической регистрацией»: клиент сам регистрируется
на их сервере логином/паролем. Для Битрикс24 это тип подключения **«Облачная АТС»**
в SIP-коннекторе (Б24 сам регистрируется у оператора), а не «Офисная АТС».

## Что пишет Tele2 в письме и что это значит

| Из письма | Что это значит |
|---|---|
| Серверы `almpbx.tele2.kz` (Алматы) / `astpbx.tele2.kz` (Астана) | Адрес SIP-сервера — выбрать один (ближайший). Его вписываем в Б24. |
| «Разрешить у себя адреса» `217.76.70.8, 217.76.70.108, 185.57.74.8, 185.57.74.108, 212.96.77.188, 212.96.77.238, 212.96.68.158, 212.96.68.168` | Это IP Tele2. Открывать их нужно **на своём файрволе/роутере**, если SIP идёт со своего оборудования (Asterisk, IP-телефоны). Для облачного Б24 файрвола у клиента нет — пункт неактуален. |
| Порты RTP `10002–59999` | Диапазон портов для голоса. Тоже про свой файрвол; в облачном Б24 ничего не делаем. |
| «Ваши публичные SIP-адреса должны быть в разрешённых у нас» | **Главный пункт.** Tele2 пускает регистрацию только с IP из белого списка. Если подключаем Б24 напрямую — регистрируются серверы телефонии Битрикс24, и в белый список Tele2 надо внести **их** IP. |

## Вариант 1. Напрямую в Битрикс24 (облачная АТС)

1. Убедиться, что в Б24 доступен SIP-коннектор (на части тарифов он платный —
   смотреть в Телефония → Подключение).
2. Запросить в поддержке Битрикс24 **актуальный список IP-адресов серверов телефонии
   для SIP-коннектора** (адресов несколько, список меняется — брать только у поддержки /
   в их справке, не из старых форумов).
3. Отправить этот список менеджеру Tele2 с просьбой добавить в разрешённые для SIP-аккаунта.
   Дождаться подтверждения.
4. В Б24: Телефония → Подключение → SIP-коннектор → **Облачная АТС** → подключить:
   - Название — удобно указать номер телефона;
   - Адрес сервера — `almpbx.tele2.kz` (или `astpbx.tele2.kz`);
   - Логин / пароль — из авторизационных данных Tele2;
   - если Tele2 дал отдельный «логин для аутентификации», порт или outbound proxy —
     заполнить в дополнительных настройках.
5. Проверить статус регистрации линии (должен стать «успешно»). Если ошибка регистрации
   (403/401/timeout) — почти всегда IP Б24 ещё не в белом списке Tele2 или неверный логин.
6. Настроить линию: Телефония → Настройки номеров → выбрать линию → очередь/ответственные
   для входящих, запись звонков, CRM-форма. Сделать линию исходящей по умолчанию.
7. Тест: входящий с мобильного, исходящий из Б24, проверить что определяется нужный CallerID
   (CallerID настраивает Tele2, а не Битрикс).

## Вариант 2. Через свою АТС на сервере со статическим IP

Если Tele2 отказывается вносить пачку чужих IP (или их список Б24 часто меняется):

- Поднять Asterisk/FreePBX на VPS со статическим IP (или использовать облачную АТС-посредника).
- Этот IP передать Tele2 в белый список; на файрволе VPS открыть IP Tele2 из письма
  (SIP 5060 UDP/TCP) и RTP `10002–59999`.
- АТС регистрируется в Tele2, а Б24 подключается к своей АТС (облачная АТС → наш сервер,
  либо интеграция через REST/приложение для Asterisk).

Дольше и дороже в поддержке, но IP один и под контролем.

## Кратко клиенту
Да, можно сразу в Битрикс24, но сначала Tele2 должен разрешить IP-адреса серверов
телефонии Битрикс24 — без этого регистрация не пройдёт. Логин/пароль в репозиторий
и в переписку не вставлять.
