# Источник сделки в канбане и автозаполнение источника

Задача клиента: в карточке канбана под названием сделки сразу видеть источник. Сейчас источник проставляется автоматически только для Facebook, у остальных (открытые линии и т. п.) поле пустое.

> Названия пунктов меню отличаются в разных версиях интерфейса. Пути не сверены на живом портале.

## 1. Показать «Источник» в карточке канбана

Строка «Продажа» под названием — это поле «Тип сделки», оно выведено в карточку по умолчанию.

1. CRM → Сделки → режим **Канбан**.
2. Шестерёнка / «...» над канбаном (или наведение на карточку) → **«Настроить поля в карточке»** («Вид карточки»).
3. Добавить поле **«Источник»**, при желании убрать «Тип».
4. Под администратором → **«Применить для всех»**, чтобы вид поменялся у всех менеджеров.

Без шага 2 поле в канбане не видно, даже если оно заполнено.

## 2. Сделать, чтобы источник заполнялся сам

Facebook заполняется сам, потому что у интеграции Facebook (лид-формы) источник задан в настройках. Для остальных каналов его нужно задать там, откуда приходит сделка.

### Открытые линии (WhatsApp, Telegram, Instagram, чат на сайте)
- Контакт-центр → нужная открытая линия → **Настроить** → блок **CRM** → поле **«Источник»** для создаваемых лидов/сделок → выбрать (например, «WhatsApp»).
- Источник задаётся на всю линию. Если все мессенджеры подключены к одной линии, различить их так не получится — вынести каналы в отдельные линии или использовать робота (ниже).

### CRM-формы на сайте
- CRM → Формы → форма → **Настройки** → «Что создавать в CRM» / дополнительно → **Источник** (например, «Сайт»).
- Если форма передаёт UTM-метки, они попадают в поля UTM сделки — их тоже можно вывести в канбан.

### Звонки
- Телефония → Настройки → номер → настройки CRM → **Источник** для создаваемых лидов/сделок (например, «Звонок»).

### Своего источника нет в списке
- CRM → Настройки → **Справочники** → **Источники** → добавить нужные значения (WhatsApp, Instagram, Сайт, Рекомендация и т. д.).

## 3. Подстраховка роботом (если где-то источник не задать)

CRM → Сделки → **Роботы** → первая стадия → робот **«Изменить элемент»** («Изменить сделку»):
- поле «Источник» = нужное значение;
- **Условие**: «Источник» пустой (и, например, «Название» содержит «Открытая линия»), чтобы не затирать источник, который уже пришёл сам.

Так все сделки из открытых линий без источника получат значение по умолчанию.

## Важно
- Всё это работает только для **новых** сделок. Старым источник проставить вручную через массовое редактирование в режиме «Список» (отметить сделки → «Редактировать» → поле «Источник»).
- Настраивать формы, открытые линии и справочники может только администратор.
