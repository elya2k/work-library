# Не работают SIP-номера Tele2 (almpbx.tele2.kz) — диагностика

Ситуация: SIP-линии Tele2 Казахстан (сервер `almpbx.tele2.kz`), подключённые к Битрикс24
через SIP-коннектор (облачная АТС), перестали работать.

Главное — понять, **где** проблема: у оператора, в настройках линии или в сети.

## 1. Что именно не работает
- Линия **не регистрируется** (статус ошибки в Б24) → п. 2–4.
- Регистрация есть, но **нет входящих** → переадресация/маршрутизация у оператора, номер (DID) привязан не к тому SIP-логину.
- Регистрация есть, но **нет исходящих** → формат номера (`7XXXXXXXXXX` / `8...` / `+7...`), CallerID, баланс/блокировка у оператора.
- Звонок идёт, но **нет звука / звук в одну сторону** → NAT/RTP, кодеки (оставить G.711 a-law/PCMA).

## 2. Статус линии в Битрикс24
Телефония → Подключение → SIP-коннектор / «Облачная АТС» → нужная линия → статус регистрации.
Коды ошибок:

| Код / ошибка | Что значит | Что делать |
|---|---|---|
| 401 / 403 Forbidden | Неверный логин/пароль, или оператор не пускает с этого IP | Проверить данные в ЛК Tele2; спросить, нет ли фильтра по IP |
| 404 Not Found | Нет такого SIP-аккаунта на сервере | Аккаунт удалён/изменён у оператора |
| 408 / Timeout | Сервер не отвечает | Сервер лежит или недоступен → п. 3 |
| 503 Service Unavailable | Сервер перегружен/на работах | Ждать / писать оператору |
| DNS / host not found | Имя `almpbx.tele2.kz` не резолвится | Сменился адрес сервера → спросить у Tele2 актуальный хост/IP |

## 3. Проверка доступности сервера (с любого ПК, Windows PowerShell)
```powershell
nslookup almpbx.tele2.kz
Test-NetConnection almpbx.tele2.kz -Port 5060
```
- `nslookup` не находит адрес → проблема DNS/адреса у оператора.
- Адрес есть, но порт 5060 TCP закрыт — это ещё не приговор (SIP обычно идёт по UDP), но если раньше
  было открыто — сервер недоступен.

Важно: в облачном Б24 регистрацию делает **сервер Битрикса**, а не офисный компьютер.
Поэтому если в офисе всё «пингуется», а в Б24 ошибка — вероятно, Tele2 закрыл доступ
для внешних IP (фильтр по IP / доступ только из своей сети). Это решает только оператор.

## 4. Заявка в Tele2 (корпоративная поддержка — номер в договоре / ЛК)
```
Компания: ...           БИН: ...           Договор: ...
Номера (SIP): ...
SIP-сервер: almpbx.tele2.kz, логины: ...
С какого времени не работает: дд.мм.гггг чч:мм
Симптом: нет регистрации / нет входящих / нет исходящих / нет звука
Ошибка в АТС: (код, например 408 Timeout / 403 Forbidden)
АТС: Битрикс24, SIP-коннектор (облачная АТС, регистрация с серверов Битрикс24)
Вопросы:
 1. Есть ли авария/работы на almpbx.tele2.kz?
 2. Не менялся ли адрес SIP-сервера, порт, транспорт (UDP/TCP)?
 3. Нет ли ограничения доступа по IP / только из сети Tele2?
 4. Активны ли SIP-аккаунты и нет ли блокировки по балансу?
```

## 5. Временный обход
- Попросить Tele2 включить **переадресацию** номеров на мобильный/другой номер на время аварии.
- Если у компании есть другая линия в Б24 — временно назначить её для исходящих.

## Нюансы
- Пароль SIP никогда не хранить в репозитории и не пересылать в открытых чатах.
- Если оператор сменил хост — поменять «Сервер» в настройках линии Б24 и сохранить, регистрация переподнимется.
