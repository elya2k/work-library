# CRM: новое поле-список («Статус клиента») и его место в карточке и фильтре

Запрос клиента: создать поле «Статус клиента» со значениями «Действующий, Расторжение, Ликвидация,
Ликвидированный, Приостановленный» и поставить его в фильтр после поля «НДС».

Поле «НДС» у клиента — пользовательское поле типа «Список» (не выбрано / Да / Нет), под ним блок
«Сквозная аналитика». Новое поле создаётся **в той же сущности**, где «НДС» (компания, сделка, контакт),
иначе в фильтре этого списка оно не появится.

## 1. Создать поле (из карточки — проще всего)
1. Открыть любую карточку этой сущности (например, компанию).
2. В блоке, где находится «НДС», внизу нажать «Создать поле»
   (или «Выбрать поле» → «Создать поле»).
3. Тип поля — **«Список»**.
4. Название: «Статус клиента».
5. Значения, каждое отдельной строкой («+ Добавить»):
   - Действующий
   - Расторжение
   - Ликвидация
   - Ликвидированный
   - Приостановленный
6. По желанию: значение по умолчанию, «Обязательное», «Множественное» — для статуса множественное **не** включать.
7. Сохранить.

Альтернатива: CRM → Настройки → Настройки форм и отчётов → Пользовательские поля → нужная сущность →
«Добавить поле» → тип «Список».

## 2. Поставить поле после «НДС» в карточке
1. Перетащить «Статус клиента» за значок ⠿ слева от названия сразу под «НДС».
2. Чтобы порядок увидели все сотрудники, менять нужно **общий вид** карточки: шестерёнка/меню блока →
   «Общий вид» (или «Применить для всех пользователей»). Это доступно администратору CRM.
   Если правили «Мой вид» — изменения увидит только сам пользователь.

## 3. Добавить поле в фильтр списка после «НДС»
1. Открыть список (CRM → Компании/Сделки…), кликнуть в строку фильтра.
2. Внизу формы фильтра — «Добавить поле» → найти «Статус клиента» → поставить галочку.
3. Перетащить поле за ⠿ сразу под «НДС».
4. «Сохранить фильтр» (сохраняется пресет). Администратор может сохранить пресет для всех пользователей
   (при сохранении/настройке фильтра — «Для всех пользователей»).

## Если поле не появилось в фильтре
- Проверить настройки поля: CRM → Настройки → Пользовательские поля → «Статус клиента» →
  «Показывать в фильтре списка» = **Да** → Сохранить, обновить страницу.
- Поле создано не в той сущности (например, в сделке, а фильтр смотрят в компаниях).
- В смарт-процессах поля и фильтр настраиваются внутри конкретного смарт-процесса.

## Готовый ответ клиенту
> Добрый день! Поле создаётся прямо в карточке:
> 1. Откройте любую карточку, в блоке с полем «НДС» нажмите внизу «Создать поле» → тип «Список».
> 2. Название — «Статус клиента», добавьте значения: Действующий, Расторжение, Ликвидация, Ликвидированный, Приостановленный → Сохранить.
> 3. Перетащите новое поле за значок ⠿ под «НДС» (чтобы порядок был у всех — правьте общий вид карточки).
> 4. В списке откройте фильтр → «Добавить поле» → отметьте «Статус клиента», перетащите его под «НДС» и нажмите «Сохранить фильтр».
>
> Если поля нет в списке фильтра — в настройках поля включите «Показывать в фильтре списка».
