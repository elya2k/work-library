# Подключение Wazzup к Битрикс24 (WhatsApp, Telegram, Instagram, Avito, VK, MAX)

> Wazzup — сервис, который подключает мессенджеры к CRM. Переписка с клиентами идёт из Битрикс24: через **открытые линии** и чат в **карточке CRM**.
> Названия пунктов меню у Wazzup и Битрикс24 периодически меняются — логика остаётся та же. Актуальные цены и тарифы — на сайте Wazzup.

## 0. Что нужно от клиента (собрать ДО подключения)

| Что | Зачем / комментарий |
|---|---|
| Доступ администратора к Битрикс24 (или админ клиента на созвоне) | Установка приложения Wazzup из Маркета и настройка открытых линий — только админ |
| E-mail для личного кабинета Wazzup | Регистрируем аккаунт **на клиента** (его почта), чтобы оплата и доступы были у него |
| Список каналов: какие номера / аккаунты подключаем | WhatsApp, Telegram, Instagram, Avito, VK, MAX, WABA |
| **WhatsApp**: телефон с этим номером **физически на руках** во время подключения | Сканирование QR-кода. Лучше WhatsApp Business. Номер должен быть «живой» (не новый вчерашний) |
| **Telegram (личный)**: номер, доступ к SMS/коду и **облачный пароль** (2FA), если включён | Код приходит в сам Telegram на телефоне |
| **Telegram-бот**: токен бота от @BotFather (или доступ к аккаунту, где бот создан) | Токен — секрет, в репозиторий/чаты не сохранять |
| **Instagram**: профессиональный аккаунт (бизнес/автор), привязанный к **странице Facebook**; доступ к Facebook-аккаунту админа страницы | В приложении Instagram включить «Разрешить доступ к сообщениям» (Настройки → Сообщения → Подключённые инструменты) |
| **Avito**: доступ к аккаунту Авито компании (логин) | Авторизация через Авито; нужен аккаунт компании/профи |
| **VK**: админ сообщества, в сообществе включены сообщения | Авторизация через VK ID админа |
| **WABA (официальный WhatsApp API)**: Meta Business-аккаунт, сайт, юрлицо, номер без активного WhatsApp | Отдельная процедура, верификация, оплата диалогов Meta — обсуждать отдельно |
| Кто отвечает в чатах (список сотрудников) и как распределять | Очередь открытой линии / ответственные |
| Что создавать при новом обращении: лид / контакт / сделка; в какой воронке | Настройка интеграции с CRM |
| Кто и как оплачивает Wazzup (карта / счёт на юрлицо, реквизиты) | Тариф считается **за каждый канал** |

## 1. Регистрация в Wazzup

1. Зайти на сайт Wazzup → **Регистрация** → e-mail клиента, пароль.
2. Подтвердить почту.
3. Включается **бесплатный тестовый период** (несколько дней) — хватает, чтобы всё настроить и проверить до оплаты.
4. Пароль от ЛК передать клиенту / хранить в менеджере паролей, **не в репозитории**.

## 2. Подключение каналов в личном кабинете Wazzup

ЛК Wazzup → **Каналы** → **Добавить канал** → выбрать тип.

### WhatsApp (через QR, «связанное устройство»)
1. В Wazzup выбрать WhatsApp → появится QR-код.
2. На телефоне клиента: WhatsApp → **Настройки → Связанные устройства → Привязка устройства** → отсканировать QR.
3. Статус канала станет «Активен».
4. Предупредить клиента:
   - телефон должен периодически быть в сети (если долго офлайн — WhatsApp отвязывает устройство, канал отваливается);
   - не выходить из WhatsApp и не переустанавливать его без нужды;
   - **никаких массовых рассылок** по холодной базе — WhatsApp банит номер. Новый номер сначала «прогреть» обычной перепиской;
   - история сообщений до подключения в CRM, как правило, не подтягивается (или подтягивается частично).

### Telegram (личный аккаунт)
1. Выбрать Telegram → ввести номер.
2. Ввести код, пришедший в Telegram на телефоне.
3. Если включена двухэтапная аутентификация — ввести облачный пароль.

### Telegram-бот
1. В @BotFather создать бота (`/newbot`) или взять существующий → получить токен.
2. Вставить токен в Wazzup. Клиенты пишут боту — сообщения идут в CRM.

### Instagram
1. Проверить: аккаунт профессиональный, привязан к странице Facebook, доступ к сообщениям для подключённых инструментов включён.
2. В Wazzup выбрать Instagram → войти через Facebook админа → выдать **все** запрашиваемые разрешения → выбрать нужную страницу/аккаунт.

### Avito / VK / MAX
- Выбрать канал → авторизоваться через аккаунт Авито / VK ID админа сообщества / по инструкции Wazzup для MAX (обычно номер + код).

## 3. Интеграция Wazzup с Битрикс24

1. ЛК Wazzup → **Интеграции** (Интеграция с CRM) → **Битрикс24** → указать адрес портала (`company.bitrix24.ru`).
2. Откроется Битрикс24 → установить приложение **Wazzup** из Маркета → согласиться с правами доступа (нужен админ портала).
3. Вернуться в ЛК Wazzup — интеграция должна отображаться как подключённая.

## 4. Настройка в Битрикс24

1. **Контакт-центр** → плитка **Wazzup** (появляется после установки приложения).
2. Для каждого канала выбрать / создать **открытую линию** (можно одну на все каналы, можно отдельную, например «WhatsApp продажи», «Instagram»).
3. В настройках открытой линии:
   - **Очередь** — сотрудники, которые отвечают; тип распределения (равномерно / по очереди / всем сразу);
   - **CRM** — что создавать для нового обращения: лид / контакт + сделка, воронка, источник (например «WhatsApp»);
   - время на ответ, автоответы, нерабочее время;
   - при желании отключить оценку качества (см. `open-lines-disable-rating.md`).
4. В ЛК Wazzup (настройки интеграции) проверить:
   - кто ответственный по умолчанию;
   - создавать ли сделку / лид при входящем от нового номера;
   - доступ сотрудников к каналам (кто с какого номера может писать).
5. Сотрудникам, которые будут писать первыми из карточки CRM, выдать доступ (в Wazzup — пользователи/права; в Битриксе — права на открытые линии).

## 5. Проверка

1. С постороннего номера написать в WhatsApp/Telegram/Instagram клиента.
2. Проверить: сообщение пришло в **открытую линию** (чат у ответственного) и создался лид/сделка с правильным источником.
3. Ответить из Битрикса — сообщение дошло до клиента.
4. Написать **первым** из карточки контакта/сделки (кнопка Wazzup / мессенджер в карточке) — сообщение дошло.
5. Проверить, что повторное сообщение с того же номера не плодит дубли, а падает в существующий контакт.

## 6. Оплата и сдача клиенту

1. До конца тестового периода клиент оплачивает тариф в ЛК Wazzup (за каждый канал; можно картой или счётом на юрлицо).
2. Передать клиенту: доступ к ЛК Wazzup, список подключённых каналов, какие линии за что отвечают, памятку для сотрудников.

## 7. Частые проблемы

| Проблема | Что делать |
|---|---|
| Канал WhatsApp «Не активен» / «Нет связи с телефоном» | Открыть WhatsApp на телефоне, проверить интернет; если отвязан — заново сканировать QR |
| Сообщения не попадают в Битрикс | Проверить, что приложение Wazzup установлено и к каналу привязана открытая линия; переподключить интеграцию в ЛК Wazzup |
| Instagram не подключается | Аккаунт не профессиональный / не привязан к странице FB / не включён доступ к сообщениям / не выданы все разрешения |
| Номер WhatsApp заблокирован | Следствие рассылок или жалоб; разблокировка через поддержку WhatsApp, не гарантируется. Предупреждать заранее |
| Дубли контактов | Настроить в Битриксе контроль дубликатов по телефону; проверить формат номера |
| Сотрудник не видит чаты | Нет в очереди открытой линии / нет прав в Wazzup |
