# Общий диск: папка с доступом только для части сотрудников

Да, можно. Два способа.

## Способ 1. Права доступа на папку (Общий диск компании)
1. Диск → Общий диск → создать папку.
2. Правый клик по папке (или «…») → «Доступ» / «Настроить права доступа».
3. Удалить унаследованное право «Все сотрудники» (или снять наследование прав от родительской папки).
4. Добавить нужных сотрудников / отделы / группы и выдать уровень:
   «Чтение», «Редактирование» или «Полный доступ».
5. Сохранить. Вложенные папки наследуют эти права.

Нюансы:
- Настраивать права на папки общего диска может администратор (или тот, у кого «Полный доступ» к диску).
- Администраторы портала видят всё независимо от прав.
- Гибкие права доступа на папках общего диска доступны не на всех тарифах облака — проверить в текущем тарифе.
- Если давать доступ отделу, новые сотрудники этого отдела получат доступ автоматически.
- Проверить: зайти под сотрудником без доступа (или попросить его) — папки не должно быть видно.

## Способ 2. Отдельная группа / проект
Создать группу (проект) с нужными участниками, у группы свой Диск — файлы видят только участники.
Подходит, если на тарифе нет настройки прав на папки, или команда и так работает в группе.
Минус: файлы живут не в общем диске, а в группе.

## Способ 3 (частный случай). Папка в «Моём диске» + «Поделиться»
Сотрудник создаёт папку у себя и подключает её выбранным коллегам.
Минус: папка принадлежит сотруднику — при увольнении возникают проблемы. Для рабочих документов лучше способ 1 или 2.
