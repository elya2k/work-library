# Телефония: как звонить через Битрикс24

## Что нужно заранее (делает администратор)
1. **Подключённая линия**, одна из:
   - SIP-коннектор (своя облачная АТС / оператор) — см. `sip-connector-find-number.md`;
   - арендованный номер Битрикс24 (нужен положительный баланс телефонии);
   - приложение-интеграция облачной АТС из Маркета (Mango, Zadarma, Телфин и т.п.) —
     тогда звонки идут через их приложение, настройки в нём же.
2. **Линия для исходящих у сотрудника**: Телефония → Пользователи телефонии →
   сотрудник → номер для исходящих звонков. Плюс общий номер по умолчанию в
   настройках телефонии.
3. **Права**: Телефония → Права доступа — у роли сотрудника должен быть разрешён
   исходящий звонок.

## Как звонить (сотрудник)
- **Из CRM** (основной способ): открыть контакт/компанию/сделку/лид → нажать на
  номер телефона или значок трубки → «Позвонить». Звонок сам привяжется к карточке,
  запись разговора попадёт в ленту.
- **Номеронабиратель**: значок телефонной трубки в панели мессенджера → набрать номер.
- **Где физически идёт разговор**:
  - браузер — нужна гарнитура и разрешить сайту доступ к микрофону (Chrome/Edge/Yandex);
  - десктоп-приложение Битрикс24 — стабильнее браузера, рекомендуется для отделов продаж;
  - мобильное приложение Битрикс24;
  - SIP-телефон / софтфон (Zoiper, MicroSIP, аппарат) — включается в настройках
    телефонии пользователя, Битрикс выдаёт данные для подключения. При звонке из CRM
    сначала звонит SIP-телефон сотрудника, после ответа — клиенту.

## Если не звонит
- «Нет доступных линий» / кнопка неактивна — у сотрудника не выбрана линия для
  исходящих или нет права на исходящий звонок.
- Звонок идёт, но не слышно — браузер не дал доступ к микрофону, либо гарнитура
  не выбрана устройством по умолчанию.
- Арендованный номер — проверить баланс телефонии.
- SIP-коннектор — проверить статус линии (подключена ли регистрация) и баланс у оператора.
- Клиенту определяется «не тот» номер — исходящий номер (CallerID) настраивается
  у оператора, а не в Битриксе.
- Названия пунктов меню могут отличаться в зависимости от версии интерфейса.
