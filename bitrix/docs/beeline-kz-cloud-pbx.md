# Подключение облачной АТС билайн (Казахстан) к Битрикс24

Ситуация: оператор (билайн KZ, business.beeline.kz → «Виртуальная АТС») выдал логин и пароль
от личного кабинета АТС. Что делать дальше.

> Важно про источники. Готовой публичной инструкции «билайн KZ + Битрикс24» нет.
> Всё, что найдено в сети по «Облачной АТС билайн», относится к **России** (cloudpbx.beeline.ru,
> приложение ПАО «Вымпелком», вход по токену) или к **Кыргызстану** (wiki.ats.beeline.kg).
> Российские инструкции с токеном и «CRM-коннектором» к казахстанскому кабинету **не применять вслепую**:
> это разные продукты. Порядок ниже: сначала смотрим, что реально есть в кабинете, потом выбираем способ.

## Шаг 0. Доступы
- Сразу сменить выданный пароль, сохранить в менеджере паролей. В репозиторий и чаты не писать.
- Уточнить, чей это логин: администратора всей АТС или одного абонента. Нужен **администраторский**.
- Права в Битрикс24: администратор портала (установка приложений, настройки телефонии).

## Шаг 1. Инвентаризация кабинета АТС
Зайти в кабинет и записать (без паролей) в README проекта клиента:
1. **Номера** — какие городские/мобильные номера подключены (+7 727…, +7 717 2…, +7 7xx…), сколько линий.
2. **Сотрудники / абоненты / внутренние номера** — кто уже заведён, у кого какие добавочные.
3. **Входящая маршрутизация** — куда сейчас идёт звонок (группа, IVR/голосовое меню, очередь).
4. **Раздел интеграций**: «Настройки → Интеграция с CRM», «Интеграции», «API», «CRM-коннектор».
   Есть ли там Битрикс24 / amoCRM. **От этого зависит выбор способа (шаг 2).**
5. **SIP-учётки** — можно ли создать SIP-аккаунт (сервер/domain, SIP proxy, логин, пароль), сколько линий.
6. **Запись разговоров** — включена ли, сколько хранится.

## Шаг 2. Выбрать способ подключения

| | А. Приложение/интеграция из кабинета АТС | Б. SIP-коннектор Битрикс24 | В. Своя интеграция по API |
|---|---|---|---|
| Когда | В кабинете есть «Интеграция с CRM → Битрикс24», или в Маркете есть приложение для билайн KZ | Интеграции нет, но АТС даёт SIP-аккаунт | Нет ни того, ни другого, но есть API АТС |
| Кто «главный» | АТС: маршрутизация, запись, очереди в АТС | Битрикс24: правила, очереди, запись в Б24 | АТС |
| Лицензия SIP-коннектора Б24 | Не нужна | **Нужна** (без неё только входящие) | Не нужна |
| Звонки сотрудников | Софтфон/мобильный АТС, WebRTC-виджет в Б24 (если есть) | Звонилка Б24 (браузер, десктоп, моб. приложение), SIP-телефон | Как в АТС |
| Плюс | Ничего не меняем в АТС, всё делает оператор | Полная телефония Б24 | Гибко |
| Минус | Зависит от приложения оператора | Платно, маршрутизация переезжает в Б24 | Нужна разработка |

**Рекомендация:** если есть вариант А — брать его. Б — запасной. В — только если А и Б невозможны
(в 2025 на фрилансе был заказ «интеграция по API ВАТС Beeline Kazakhstan с Б24» — значит, готового
решения у кого-то не нашлось; проверять на месте).

## Вариант А. Интеграция через кабинет АТС (REST-приложение)
По аналогии с ВАТС билайн KG, Kcell, Казахтелеком (там одна платформа Cloud PBX Solutions,
у каждого оператора своё приложение в Маркете Б24):
1. В Битрикс24 → Маркет → поиск «билайн», «beeline», «Виртуальная АТС». Ставить приложение
   **для Казахстана**. Приложения «Beeline Кыргызстан» и «Облачная АТС билайн бизнес» (Россия) не подойдут.
   Для облачного Б24 может понадобиться подписка на Маркет — проверить.
2. В кабинете АТС: «Настройки → Интеграция с CRM → Битрикс24 → Подключить», указать домен портала
   (`company.bitrix24.kz`), разрешить доступ под администратором Б24.
   Для коробки: только домен (не IP) и рабочий SSL, иначе ошибки (на KG-платформе — ошибка 500).
3. **Сопоставить сотрудников** АТС ↔ пользователей Б24. Звонки несопоставленных в CRM не попадают.
   Каждого нового сотрудника потом сопоставлять вручную.
4. Настроить сценарии интеграции: создание лида/сделки по новому номеру, ответственный,
   запись разговора в карточку, всплывающая карточка, звонок по клику, WebRTC-виджет (если есть).
5. Если вместо этого кабинет просит **токен** — генерировать в кабинете АТС и вставлять в приложение
   (так устроено в российской версии). Если неясно — спросить поддержку билайн KZ.

## Вариант Б. SIP-коннектор Битрикс24
1. В кабинете АТС создать SIP-аккаунт (у сотрудника/номера), задать число линий, сгенерировать пароль.
   Записать: сервер (domain), SIP proxy (если есть), логин (SIP user ID), пароль.
2. Б24 → Телефония → Подключение → **Подключить облачную АТС** (SIP-коннектор):
   сервер, логин, пароль, название линии = номер (иначе потом непонятно, см. `sip-connector-find-number.md`).
3. Дождаться статуса «Зарегистрирован». Если нет — сверить сервер/прокси с оператором,
   уточнить, не ограничен ли SIP по IP (Б24 облачный — внешние IP Битрикса).
4. Купить лицензию SIP-коннектора (цена в тенге — в самом портале; одна лицензия на все SIP-линии).
   Без неё работают только входящие.
5. Настроить линию: правила входящих (очередь/группа, время работы, голосовое меню),
   запись разговоров, создание лида/сделки, исходящий номер по умолчанию.
6. Сотрудникам — права на телефонию и номер по умолчанию.
7. Исходящий CallerID (какой номер видит клиент) настраивается **у оператора**, не в Б24.

## Вариант В. Своя интеграция по API
Нужно от билайн: документация API, токен, вебхуки событий звонка (начало/ответ/конец, ссылка на запись).
В Б24: `telephony.externalcall.register` → `telephony.externalcall.finish` (+ `attachRecord`),
`telephony.externalLine.add` для номеров. Это отдельный проект → `projects/<клиент>-beeline-b24/`.

## Специфика Казахстана
- Номера: хранить в CRM в формате `+7XXXXXXXXXX`. Код страны +7, как у РФ, — поиск клиента по номеру
  работает, но номера «8 7xx…» и «7xx…» без кода лучше привести к единому виду, иначе дубли лидов.
- Запись разговоров = обработка персональных данных (Закон РК «О персональных данных и их защите»):
  включить автоинформатор «разговор может быть записан» в приветствии АТС.
- Портал обычно на `bitrix24.kz` — набор приложений Маркета и цены отличаются от .ru,
  поиск приложения делать в самом портале.
- Сайты beeline.kz не всегда открываются извне РК — инструкции оператора смотреть из Казахстана.

## Вопросы менеджеру / поддержке билайн KZ
1. Есть ли официальная интеграция ВАТС с Битрикс24? Через кабинет («Интеграция с CRM») или приложение в Маркете? Как называется?
2. Если нет — даёте ли SIP-аккаунты для внешней АТС/Битрикс24? Сервер, прокси, порт, транспорт (UDP/TCP/TLS), кодеки, лимит линий, ограничение по IP?
3. Есть ли API и вебхуки? Документация?
4. Как настраивается исходящий номер (CallerID) и можно ли звонить с городского номера с мобильных сотрудников?
5. Запись разговоров: где хранится, сколько, можно ли передавать в CRM?
6. Логин в кабинете — администратор всей АТС?

## Чек-лист проверки после подключения
- [ ] Входящий на каждый номер → звонок у нужных сотрудников, карточка всплывает.
- [ ] Новый номер → создан лид/сделка, ответственный верный.
- [ ] Известный клиент → звонок в его карточке, а не новый лид.
- [ ] Исходящий из карточки CRM → у клиента определился правильный номер компании.
- [ ] Пропущенный → есть в CRM + задача/уведомление.
- [ ] Запись разговора открывается из карточки.
- [ ] Звонок из мобильного приложения Б24 / с мобильного сотрудника (если используется).
- [ ] Звонок вне рабочего времени → голосовая почта / переадресация.
