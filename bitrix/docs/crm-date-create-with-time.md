# CRM: дата создания с часами и минутами (список и канбан)

Симптом: в сделках вместо точного времени создания видно «сегодня», «вчера»,
«5 минут назад» или просто «1 октября» — без часов и минут.

## Режим «Список» — решается настройкой
1. CRM → Сделки → режим «Список».
2. Шестерёнка (⚙️) в левом верхнем углу таблицы.
3. Отключить отображение дат в относительном формате.
4. После этого в колонке «Дата создания» показывается полная дата и время
   (например, `01.10.2026 14:35`).

Настройка личная — каждый сотрудник включает у себя сам (или администратор
применяет вид списка для всех, если это доступно в тарифе).

## Режим «Канбан» — штатной настройки нет
На карточке канбана дата создания выводится в коротком формате, время туда
не добавить. Обходной путь:
1. Создать пользовательское поле сделки типа «Дата/время», например «Создана (время)».
2. Робот на первой стадии: «Изменить элемент» → поле «Создана (время)» =
   `{{Дата создания}}`. Робот срабатывает при создании сделки.
3. Канбан → «Настроить вид карточки» → вывести это поле на карточку.

Для уже существующих сделок поле заполнить массово (бизнес-процесс по списку
или REST: `crm.deal.update` с `UF_CRM_...` = `DATE_CREATE`).
