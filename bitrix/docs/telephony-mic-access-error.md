# «Не удалось получить доступ к веб-камере или микрофону» при звонке, хотя доступ разрешён

Сообщение: «Вы не можете позвонить, так как не удалось получить доступ к вебкамере
или микрофону». Разрешение для сайта в браузере при этом выдано.

Суть: браузер разрешил, но микрофон не отдаёт кто-то другой — ОС, другая программа,
антивирус или выбрано не то устройство.

## Быстрая диагностика (2 минуты)
1. Открыть любой тест микрофона в том же браузере.
   - Не работает → проблема в ОС/драйвере/антивирусе/занятости, а не в Битриксе.
   - Работает → проблема в настройках браузера/Битрикса для этого сайта.
2. Попробовать другой браузер и десктоп-приложение Битрикс24 — сразу сужает круг.

## Причины по частоте
1. **Микрофон запрещён на уровне ОС** (самое частое, когда «в браузере всё разрешено»):
   - Windows: Параметры → Конфиденциальность и защита → Микрофон → включить
     «Доступ к микрофону», «Разрешить приложениям» и «Разрешить классическим
     приложениям». То же для «Камера».
   - macOS: Системные настройки → Конфиденциальность и безопасность → Микрофон
     (и Камера) → включить для браузера / приложения Битрикс24. После — перезапустить его.
2. **Микрофон занят другой программой**: Zoom, Teams, Telegram-звонок, второй
   открытый Битрикс (вкладка + десктоп-приложение одновременно). Закрыть лишнее.
   Windows: Звук → устройство записи → Свойства → Дополнительно → снять
   «Разрешить приложениям использовать устройство в монопольном режиме».
3. **Выбрано не то / несуществующее устройство**: гарнитуру переподключили, а браузер
   держит старое. Chrome: значок замка/настроек слева от адреса → Настройки сайтов →
   Микрофон → выбрать гарнитуру; или chrome://settings/content/microphone —
   выпадающий список устройства вверху. Проверить устройство по умолчанию в ОС.
4. **Антивирус блокирует камеру/микрофон**: Kaspersky («Защита веб-камеры»,
   контроль микрофона), ESET и т.п. — добавить браузер/Битрикс24 в разрешённые.
5. **Сбой сохранённого разрешения**: значок замка у адреса → «Сбросить разрешения» →
   обновить страницу (Ctrl+F5) → заново разрешить.
6. **Удалённый рабочий стол / виртуалка**: в RDP микрофон должен быть проброшен
   (настройки подключения → Локальные ресурсы → Звук → Запись).
7. **Коробочный Битрикс по http**: браузеры дают микрофон только на https.
8. **Камеры нет совсем**, а звонок видео — звонить аудио (для телефонии камера не нужна).

## Нюансы
- Десктоп-приложение — отдельная программа: разрешение ОС нужно именно ему, а не браузеру.
- После изменения разрешений в ОС браузер/приложение нужно полностью перезапустить.
