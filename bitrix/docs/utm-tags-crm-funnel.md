# UTM-метки в воронке Битрикс24 (лиды и сделки)

В CRM Битрикс24 уже есть системные поля для UTM — создавать свои поля не нужно:

| Поле в карточке | Код поля (REST) | Пример |
|---|---|---|
| UTM Source — источник | `UTM_SOURCE` | `yandex`, `google`, `instagram` |
| UTM Medium — тип трафика | `UTM_MEDIUM` | `cpc`, `social`, `email` |
| UTM Campaign — кампания | `UTM_CAMPAIGN` | `black_friday` |
| UTM Content — объявление | `UTM_CONTENT` | `banner_1` |
| UTM Term — ключевое слово | `UTM_TERM` | `купить_диван` |

Поля есть у лидов, сделок, контактов и компаний. При конвертации лида в сделку UTM переносятся.

## 1. Показать UTM в карточке сделки/лида
По умолчанию блок часто скрыт.
1. Открыть любую сделку нужной воронки.
2. В блоке «О сделке» → «Выбрать поле» (или «Создать раздел» → «Выбрать поле»).
3. Отметить UTM Source / Medium / Campaign / Content / Term.
4. Чтобы так было у всех: меню карточки (шестерёнка) → «Общий вид карточки для всех пользователей» /
   «Применить для всех». Нужны права администратора.

Карточка настраивается отдельно для каждой воронки — повторить в каждой, где нужны метки.

## 2. Откуда метки попадают в CRM

### Вариант А. CRM-формы Битрикс24 на сайте — проще всего
- Форма вставлена на сайт кодом Б24 (или кодом виджета) → UTM из адреса страницы подхватываются
  автоматически и пишутся в лид/сделку.
- Проверить, что код стоит на **всех** страницах сайта (иначе метка с посадочной теряется при переходе).
- Для прямой ссылки на форму метки можно дописать к ссылке: `https://.../pub/form/...?utm_source=...`.
- В настройках формы → «Дополнительно» можно добавить скрытые поля / «Получить значение из URL»,
  если нужны свои параметры (например `yclid`, `gclid`).

### Вариант Б. Сквозная аналитика (CRM → Аналитика → Сквозная аналитика)
1. Подключить сайт — поставить код отслеживания на все страницы.
2. Подключить рекламные кабинеты (Яндекс Директ, Google Ads, VK и т.д.).
3. Источники в сквозной аналитике определяются по `utm_source` — проверить, что значение в ссылках
   совпадает с тем, что указано в настройке источника.
4. Ссылки удобно собирать встроенным «Генератором UTM-меток» там же.
5. Плюс: метки цепляются и к звонкам (подмена номера) и к чатам с сайта, не только к формам.

### Вариант В. Свои формы сайта → REST / вебхук
Сайт сам ловит UTM из URL, хранит в cookie и передаёт при отправке заявки:

```js
// 1) на всех страницах — запомнить метки при входе (30 дней)
(function () {
  const keys = ['utm_source', 'utm_medium', 'utm_campaign', 'utm_content', 'utm_term'];
  const p = new URLSearchParams(location.search);
  if (!keys.some(k => p.get(k))) return;            // нет меток — не перезаписываем старые
  keys.forEach(k => {
    document.cookie = `${k}=${encodeURIComponent(p.get(k) || '')}; path=/; max-age=${60*60*24*30}`;
  });
})();

// 2) при отправке формы — достать
function getUtm() {
  const out = {};
  document.cookie.split('; ').forEach(c => {
    const [k, v] = c.split('=');
    if (k.startsWith('utm_')) out[k.toUpperCase()] = decodeURIComponent(v || '');
  });
  return out; // { UTM_SOURCE: ..., UTM_MEDIUM: ... }
}
```

Отправка на сервере (PHP, вебхук берётся из конфига, **не хардкодить в коде/репозитории**):

```php
<?php
$webhook = getenv('B24_WEBHOOK'); // https://портал.bitrix24.ru/rest/1/xxxx/
$fields = [
    'TITLE'          => 'Заявка с сайта',
    'CATEGORY_ID'    => 0,              // ID воронки (0 — общая)
    'SOURCE_ID'      => 'WEB',
    'UTM_SOURCE'     => $_POST['UTM_SOURCE']   ?? '',
    'UTM_MEDIUM'     => $_POST['UTM_MEDIUM']   ?? '',
    'UTM_CAMPAIGN'   => $_POST['UTM_CAMPAIGN'] ?? '',
    'UTM_CONTENT'    => $_POST['UTM_CONTENT']  ?? '',
    'UTM_TERM'       => $_POST['UTM_TERM']     ?? '',
];
$ch = curl_init($webhook . 'crm.deal.add.json');   // или crm.lead.add.json
curl_setopt_array($ch, [
    CURLOPT_POST => true,
    CURLOPT_POSTFIELDS => http_build_query(['fields' => $fields]),
    CURLOPT_RETURNTRANSFER => true,
]);
$res = curl_exec($ch);
```

## 3. Использование UTM в воронке
- **Фильтр списка/канбана**: фильтр → «Добавить поле» → UTM Source и т.д. → сохранить как пресет
  («Директ», «Instagram»…).
- **Роботы по условию**: в «Роботах» стадии → робот (сменить ответственного, поставить задачу,
  перевести в другую воронку) → «Условие» → поле UTM Source = `yandex`.
  Так можно раскидывать заявки по воронкам/менеджерам по источнику рекламы.
- **Заполнить «Источник» по UTM**: робот «Изменить элемент» с условием по UTM → поле «Источник».
- **Отчёты**: CRM → Аналитика (отчёты по сделкам) / BI-конструктор — группировка по UTM-полям;
  сквозная аналитика — расходы vs. продажи по каналам.

## 4. Правила разметки ссылок
- Только латиница, нижний регистр, без пробелов (`black_friday`, а не `Black Friday`).
- Единый словарь значений `utm_source` / `utm_medium` для всех кампаний — иначе отчёты разъезжаются
  (`yandex` и `Yandex` — разные источники).
- В Директе можно использовать динамические параметры: `utm_campaign={campaign_id}&utm_content={ad_id}&utm_term={keyword}`.

## 5. Проверка
1. Открыть сайт по ссылке `?utm_source=test&utm_medium=test&utm_campaign=test`.
2. Перейти на другую страницу, отправить заявку.
3. В CRM в карточке сделки/лида должны быть значения `test`.
4. Удалить тестовую заявку.

## Частые проблемы
- **Метки пустые** — код формы/аналитики стоит не на всех страницах; редирект на сайте
  (http→https, с www на без www) срезает параметры из URL; форма в iframe без передачи URL.
- **Заявка пришла, а UTM нет только в сделке** — сделка создана не из лида, а роботом/вручную;
  либо форма создаёт контакт, а сделку — робот: UTM нужно передать роботом «Изменить элемент».
- **Чаты/WhatsApp без UTM** — мессенджеры UTM не передают; помогает только сквозная аналитика
  (виджет на сайте) или стартовое сообщение с кодом кампании.
- **Повторный клиент** — при включённом контроле дублей метки могут остаться от первого обращения;
  смотреть, что писать в существующую сделку/лид.
