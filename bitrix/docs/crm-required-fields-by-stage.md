# CRM: обязательные поля при переходе на стадию (окно «Для изменения стадии сделки заполните обязательные поля»)

Окно появляется, когда у полей включено «Обязательное» для конкретных стадий
воронки. Набор полей в окне = все поля, обязательные на целевой стадии и ещё не заполненные.
Меняется в настройках самих полей — отдельной настройки «окна» нет.

## Убрать поле из обязательных на стадии
Карточка любой сделки этой воронки → навести на поле → «Настроить» (шестерёнка/карандаш) →
блок «Обязательное поле»:
- если стоит «На всех стадиях» — переключить на выбор стадий и оставить только нужные;
- если выбраны стадии — снять нужные (например, «Квал», «Встреча»);
- если поле вообще не должно быть обязательным — снять галочку.
Сохранить. Настройка стадий действует в рамках воронки — для каждой воронки отдельно.

## Добавить новое обязательное поле
Карточка → раздел «О сделке» → «Создать поле» → тип → название →
«Обязательное поле» → выбрать стадии.

## Условное поле «если да — впиши сумму»
Штатно обязательность по стадии не умеет зависеть от значения другого поля.
И в окне смены стадии показываются только обязательные поля.

Вариант А (рекомендуется) — два поля + контроль роботом:
1. «Первоначальный взнос» — тип «Список», значения «Имеется» / «Нет»,
   обязательное на нужных стадиях → появится в окне.
2. «Сумма первоначального взноса» — тип «Деньги», НЕ обязательное, поставить в карточке
   сразу под первым полем.
3. Робот на стадиях (с условием): если «Первоначальный взнос» = «Имеется» и сумма
   не заполнена → задача/уведомление ответственному «заполнить сумму»
   (при желании — робот «Изменить стадию» возвращает на предыдущую).
Минус: сумму вписывают уже в карточке, не в окне.

Вариант Б — одно поле:
«Первоначальный взнос (сумма)» — тип «Деньги», обязательное на стадиях,
договорённость «нет взноса = 0». Проще, поле сразу в окне. Перед внедрением проверить,
что Битрикс принимает 0 как заполненное значение.

## Нюансы
- Права: администратор CRM.
- Поля общие для всей сделки — переименование/удаление поля влияет на все воронки и отчёты;
  ненужные поля лучше не удалять, а снимать обязательность (данные сохранятся).
- Уже созданные сделки окно не трогает — оно срабатывает только при смене стадии.

## «Выбрал Да — появилась строка для суммы» (динамическое поле)
Штатно карточка CRM так не умеет: поле показывается всегда, независимо от значения
другого поля. Решения:
1. **Приложение из Битрикс24.Маркет** (самый близкий к задаче вариант):
   - «Обязательные поля по условию» (Redham Digital) — поле «Сумма» становится
     обязательным, только если в «Первоначальный взнос» выбрано «Да».
     Работает с полями «Список» и «Да/Нет».
   - «Каскады24: Зависимые поля» (Overplan), «Зависимые поля» (SafeKit) —
     поле «Сумма» скрыто и появляется только при «Да».
   Обычно платные + нужна подписка Маркета; перед покупкой — тестовый период и проверка,
   срабатывает ли правило в окне смены стадии, а не только в карточке.
2. **Коробка** — свой JS в карточке (скрывать/показывать поле по значению).
3. **Без приложений** — вариант А выше (два поля + робот-напоминание).

Поле «Первоначальный взнос» делать типа **«Список» (Да / Нет)**, а не «Да/Нет»:
у «Да/Нет» всегда есть значение по умолчанию, поэтому обязательность не заставит
менеджера сделать выбор, а у списка есть «не выбрано».
