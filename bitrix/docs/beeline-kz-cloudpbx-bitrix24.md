# Beeline KZ Cloud PBX (cloudpbx.beeline.kz) ↔ Битрикс24: подключение и типовые проблемы

## Способы подключения
1. **SIP-коннектор Битрикс24 («Облачная АТС»)** — Телефония → Подключение → Облачная АТС.
   Битрикс24 регистрируется на АТС Beeline как SIP-клиент от имени внутреннего номера:
   нужны сервер (SIP-домен Beeline), логин (обычно внутренний номер, напр. `0658`) и пароль
   SIP-аккаунта из личного кабинета cloudpbx.beeline.kz (карточка сотрудника → данные SIP).
   Требуется платная подписка «SIP-коннектор» в Битрикс24.
2. **Стыковка по линиям из кабинета Beeline** — в FAQ личного кабинета
   (https://cloudpbx.beeline.kz/VPBX/Profile/FAQ) есть документ «Стыковка с CRM Bitrix24
   по линиям»: интеграция настраивается на стороне АТС (события звонков уходят в Б24 через
   REST/вебхук). Кабинет доступен только из KZ.
3. **Сторонние коннекторы** — Albato, algomix «Билайн телефония» и т.п. (платные, в основном
   под российскую ВАТС Билайн — для KZ проверять совместимость).

## Связь со статусом сотрудника в кабинете Beeline
- Кружок «Статус в Call-центре» в списке сотрудников показывает, активен ли оператор
  (зарегистрировано ли устройство / авторизован ли в очередях). Пустой кружок = не в сети.
- Если номер подключается к Б24 через **SIP-коннектор**, то Битрикс24 и есть «устройство»
  этого внутреннего номера. Регистрация не проходит → в кабинете Beeline сотрудник серый /
  «не в сети», звонки в Б24 не приходят. То есть пустой индикатор и проблема подключения —
  **две стороны одной неисправности** (нет SIP-регистрации).
- Если интеграция «по линиям» (REST), индикатор к ней отношения не имеет: он отражает только
  телефонную регистрацию устройства сотрудника.

## Чек-лист при «не подключается номер»
1. **Логин/пароль SIP**: логин — внутренний номер; пароль — именно SIP-пароль из карточки
   сотрудника (не пароль от кабинета). После смены пароля в кабинете обновить в Б24.
2. **Одна регистрация на аккаунт**: если под этим же внутренним номером уже зарегистрирован
   софтфон или IP-телефон, АТС может не пускать вторую регистрацию (или выбивать первую).
   Отключить другое устройство и проверить.
3. **Гео/IP-ограничения**: Beeline KZ может пускать SIP-регистрацию только с казахстанских IP.
   SIP-серверы облачного Битрикс24 стоят за рубежом — тогда регистрация никогда не пройдёт;
   уточнять в бизнес-поддержке Beeline, разрешают ли регистрацию с IP Битрикс24 / есть ли
   белый список.
4. **Подписка SIP-коннектор** в Б24 активна; линия включена и выбрана в маршрутизации
   (Телефония → Настройки → номер по умолчанию, права на исходящие).
5. **Сотрудник не заблокирован** в кабинете Beeline (колонка «Заблокирован»), номер активен.
6. **Статус линии в Б24**: Телефония → Подключение → у линии статус регистрации
   («подключено/ошибка»). Код ошибки (401/403/408) сузит причину:
   - 401/403 — неверные логин/пароль или IP не разрешён;
   - 408/таймаут — сервер недоступен (адрес сервера, порт, блокировка по гео).
7. **Проверка снизу вверх**: сначала зарегистрировать под этим номером обычный софтфон
   (Zoiper/MicroSIP) с теми же данными. Регистрируется → данные верны, проблема на стороне
   Б24/маршрутизации. Не регистрируется → проблема в кабинете Beeline (пароль, блокировка).
