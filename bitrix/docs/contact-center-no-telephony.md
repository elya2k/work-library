# Контакт-центр CRM: почему нет плитки «Телефония»

Симптом: CRM → Контакт-центр — есть открытые линии, формы, мессенджеры, а телефонии нет
(или плитка серая / не открывается).

## Причины и что проверить (по частоте)
1. **Права пользователя.** Контакт-центр показывает только то, что пользователь может настраивать.
   Не администратор → плитки телефонии может не быть. Проверить под админом;
   права: Телефония → Настройки → Права доступа.
2. **Телефония скрыта/убрана из меню.** Плитка может быть ниже или в «Ещё».
   Сам раздел — левое меню → «Ещё» → «Телефония» (можно вернуть в меню).
   Прямая ссылка: `https://<портал>/telephony/`.
3. **Коробка: модуль не установлен.** Администрирование → Marketplace → Установленные решения
   (или Настройки → Модули) → «Телефония» (`voximplant`). Нет модуля — нет плитки.
   Плюс редакция коробки должна включать телефонию, а портал — быть привязан к активной лицензии.
4. **Тариф / регион облака.** Аренда номеров и SIP-коннектор зависят от тарифа и страны портала;
   в части регионов отдельные функции недоступны. Проверить: Тарифы → что входит.
5. **Новый интерфейс.** В свежих версиях Контакт-центр переделан, телефония может открываться
   отдельно (раздел «Телефония»), а в Контакт-центре быть только ссылкой на него.

## Быстрая диагностика
- Открыть `/telephony/` под администратором:
  - открывается → дело в правах/меню (п. 1–2, 5);
  - 404 / «модуль не установлен» → п. 3;
  - «недоступно на вашем тарифе» → п. 4.

## Подробно: модуль «Телефония» в коробке (`voximplant`)
В облаке модулей нет, этот раздел только для коробки.

### Проверить, установлен ли
- Админка: `/bitrix/admin/module_admin.php` (Настройки → Настройки продукта → Модули) → строка «Телефония (voximplant)».
- Или PHP-консоль `/bitrix/admin/php_command_line.php`:
  ```php
  var_dump(\Bitrix\Main\ModuleManager::isModuleInstalled('voximplant'));
  ```

### Установить
1. В списке модулей «Телефония» → «Установить».
2. Если модуля в списке нет: Обновления (`/bitrix/admin/update_system.php`) → поставить все обновления →
   Marketplace → Обновление решений → «Телефония».
   Не скачивается → лицензия истекла или редакция не включает телефонию (проверить в лицензии / у партнёра).
3. Сбросить кеш: Настройки → Настройки продукта → Автокеширование → «Очистить кеш».

### Зависимости (без них плитка есть, но звонки не работают)
- `im` (мессенджер) и `pull` (Push and Pull) + работающий push-сервер (в BitrixVM включается в меню ВМ):
  без него не всплывает карточка входящего звонка.
- Портал доступен из интернета по публичному адресу с HTTPS — облачный сервис телефонии шлёт события
  на портал. Адрес указывают в настройках модуля «Телефония» (`/bitrix/admin/settings.php?mid=voximplant`).
- Активный лицензионный ключ: через него портал привязывается к облачной телефонии Битрикс24.
- Для браузерных звонков (WebRTC) — HTTPS обязателен.

### После установки
- Телефония → Подключение: арендовать номер, SIP-коннектор или облачная АТС.
- Выдать права (Телефония → Права доступа) и добавить пользователей в группы очереди.
- Плитка в Контакт-центре появится; если нет — проверить права текущего пользователя.
