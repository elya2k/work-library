# Контакт-центр CRM: почему нет плитки «Телефония»

Симптом: CRM → Контакт-центр — есть открытые линии, формы, мессенджеры, а телефонии нет
(или плитка серая / не открывается).

## Причины и что проверить (по частоте)
1. **Права пользователя.** Контакт-центр показывает только то, что пользователь может настраивать.
   Не администратор → плитки телефонии может не быть. Проверить под админом;
   права: Телефония → Настройки → Права доступа.
2. **Телефония скрыта/убрана из меню.** Плитка может быть ниже или в «Ещё».
   Сам раздел — левое меню → «Ещё» → «Телефония» (можно вернуть в меню).
   Прямая ссылка: `https://<портал>/telephony/`.
3. **Коробка: модуль не установлен.** Администрирование → Marketplace → Установленные решения
   (или Настройки → Модули) → «Телефония» (`voximplant`). Нет модуля — нет плитки.
   Плюс редакция коробки должна включать телефонию, а портал — быть привязан к активной лицензии.
4. **Тариф / регион облака.** Аренда номеров и SIP-коннектор зависят от тарифа и страны портала;
   в части регионов отдельные функции недоступны. Проверить: Тарифы → что входит.
5. **Новый интерфейс.** В свежих версиях Контакт-центр переделан, телефония может открываться
   отдельно (раздел «Телефония»), а в Контакт-центре быть только ссылкой на него.

## Быстрая диагностика
- Открыть `/telephony/` под администратором:
  - открывается → дело в правах/меню (п. 1–2, 5);
  - 404 / «модуль не установлен» → п. 3;
  - «недоступно на вашем тарифе» → п. 4.
