# Битрикс24 + Виртуальная АТС Freedom Telecom (Казахстан)

Справка оператора: https://helpguide.vpbx.ftel.kz/bitrix24_setup (раздел «Битрикс24»).
Есть два способа. Оператор рекомендует **способ 1 (приложение/виджет)**.
Оба сразу не включать: звонки задваиваются, пропадает кнопка «Ответить».

## Способ 1. Интеграция из личного кабинета ВАТС (рекомендуется)
**Всё настраивается в личном кабинете Freedom Telecom, не в Битрикс24.**
Битрикс24 только авторизует приложение «Виртуальная АТС Freedom Telecom» (разработчик Cloud PBX Solutions).
Раздел Битрикс24 «Телефония» / плитка в Контакт-центре здесь **не используются** — линии, SIP,
очереди там не настраивать (и не удивляться, что там пусто).

С апреля 2024 — новый виджет с WebRTC: звонить можно прямо из браузера в Битрикс24.
Старую интеграцию нужно обновить.

Что нужно: права администратора в ЛК ВАТС и в Битрикс24. Для коробки — домен и рабочий SSL.
В облаке для приложений из Маркета может понадобиться подписка на Маркет (зависит от тарифа).

### В личном кабинете ВАТС
1. Сотрудники, номера, входящая схема (кто получает звонок, очередь, IVR), запись разговоров —
   всё в ЛК, как обычно.
2. Настройки → «Интеграция с CRM» → «Битрикс24» → адрес портала
   (`company.bitrix24.kz`; для коробки обязательно доменное имя) → «Подключить».
3. Сопоставить сотрудников ВАТС с пользователями Битрикс24.
   Звонки в CRM пишутся **только у сопоставленных**.
4. Там же настроить поведение интеграции:
   - автосоздание лида / контакта / сделки при звонке с неизвестного номера
     (что создаётся — зависит от режима CRM: классический или простой);
   - ответственный — тот, кто принял или пропустил звонок;
   - передача записей разговоров в CRM (запись может быть платной опцией тарифа ВАТС).
5. Диагностика и уведомления об ошибках (Telegram / почта) — тоже в «Интеграция с CRM».
   Частые проблемы: https://helpguide.vpbx.ftel.kz/bitrix_problems

### В Битрикс24 (только это)
- Один раз под админом разрешить установку/доступ приложения (окно авторизации при «Подключить»).
- Сотрудникам: открыть Битрикс24 в браузере, разрешить микрофон, войти в виджет АТС.

## Способ 2. SIP-коннектор (встроенная телефония Битрикс24)
Минусы: нужна платная лицензия SIP-коннектора Битрикс24 (отдельно от тарифа),
оператор этот путь не рекомендует.

1. В ВАТС создать сотрудника / SIP-учётку → взять сервер, логин, пароль.
2. Битрикс24 → Телефония → Подключение → «Облачная SIP-АТС».
3. Заполнить: название (удобно — номер), сервер, логин (**без** `@домен`, иначе ошибка 500), пароль.
4. Статус в Битрикс24 «успешно», в ВАТС сотрудник зелёный → настроить линию
   (очередь, запись, CRM) в Телефония → Настройки → линия.
Подробно: https://helpguide.vpbx.ftel.kz/bitrix24_sip_connector

## Тестовая настройка и проверка (способ 1, ~30 минут)
Сначала подключаем одного сотрудника, проверяем, потом добавляем остальных.

### Минимальная настройка для теста
Всё, кроме пп. 4–5, — в личном кабинете ВАТС.
1. Один сотрудник (вы) с внутренним номером; входящая схема номера → сразу на него
   (без IVR и очереди, чтобы не путаться).
2. Интеграция с CRM → Битрикс24: подключить портал, сопоставить **только себя**.
3. Включить: автосоздание лида при звонке с неизвестного номера, запись разговоров, передача записей в CRM.
4. Битрикс24: удалить из CRM контакт со своим мобильным (если есть) — для проверки автосоздания.
5. Браузер: открыть Битрикс24 в Chrome, разрешить микрофон, войти в виджет АТС.

### Сценарии
| # | Что делаем | Ожидаем |
|---|------------|---------|
| 1 | С мобильного звоним на номер компании | Звонит виджет, всплывает карточка «новый номер» |
| 2 | Отвечаем, говорим 20 сек, кладём трубку | В CRM новый лид, ответственный — вы, в ленте звонок с записью (запись может появиться через 1–5 мин) |
| 3 | Звоним ещё раз | Карточка уже с именем лида, новый лид не создаётся |
| 4 | Звоним и не отвечаем | Пропущенный звонок в ленте лида, уведомление / задача на перезвон |
| 5 | Из карточки лида «Позвонить» | Звонит мобильный, у собеседника номер компании, звонок в ленте |
| 6 | Звоним с номера существующего контакта | Звонок привязан к этому контакту, дубль не создан |

Если всё прошло — сопоставить остальных сотрудников, вернуть IVR/очереди, повторить сценарии 1 и 5.

### Если не прошло
Сначала смотреть ЛК ВАТС → История звонков: дошёл ли звонок до АТС и кому.
- Звонка нет в истории ЛК → проблема у оператора/номера, Битрикс24 ни при чём.
- В ЛК есть, карточки нет → сотрудник не сопоставлен (ЛК) / виджет не авторизован / браузер блокирует уведомления.
- Звонок есть, но в CRM пусто → сопоставление или автосоздание в ЛК → Интеграция с CRM.
- Нет записи → запись не включена в тарифе / выключена передача записей (ЛК).
- Исходящий не идёт → нет доступа к микрофону, не HTTPS (коробка), не выбран исходящий номер (ЛК).
- Звонки задваиваются → включены одновременно приложение и SIP-коннектор; оставить одно.
- Ошибки интеграции: ЛК ВАТС → Интеграция с CRM → диагностика.
