# «Срок годности контрольного слова истек. Вам необходимо запросить его повторно»

Окно «Восстановление пароля» Битрикс24. Контрольное слово — одноразовый код внутри
ссылки из письма (приглашение или восстановление пароля). Ссылка устарела.

## Почему
- Ссылка старая: у ссылок из писем приглашения/восстановления ограниченный срок.
- Запросили восстановление несколько раз — работает только **последнее** письмо.
- Ссылку уже открывали (в т.ч. автоматически — проверка ссылок почтовым сервисом/антивирусом).

## Что делать
**Пользователь:** страница входа портала → «Забыли пароль?» → ввести свою почту →
открыть **самое свежее** письмо (проверить «Спам») и сразу перейти по ссылке →
задать пароль. Старые письма не использовать.

**Администратор (если сотрудник ещё не принял приглашение):**
Сотрудники → найти сотрудника → «Пригласить повторно» / повторить приглашение →
сотрудник открывает новое письмо сразу.

Если и новая ссылка «протухает» мгновенно — открыть письмо в другом браузере/с компьютера;
вероятно, ссылку «съедает» проверка ссылок в почте.
