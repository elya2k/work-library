# Заявка оператору на SIP-номер: что писать в «Наименование и тип оборудования»

Ситуация: клиент берёт у оператора виртуальный (SIP) номер, чтобы подключить его
в Битрикс24 через SIP-коннектор. В заявке оператора есть пункт «наименование и тип
оборудования» и просят указать АТС. Физической АТС у клиента нет — АТС облачная,
это сам Битрикс24 (модуль «Телефония»).

## Что писать

| Поле заявки | Что указать |
|---|---|
| Наименование оборудования | Облачная виртуальная АТС «Битрикс24» (модуль «Телефония», SIP-коннектор) |
| Тип оборудования | Программная (облачная) IP-АТС, протокол SIP 2.0 |
| Производитель / разработчик | 1С-Битрикс (Битрикс24) |
| Место установки | Облачная инфраструктура Битрикс24 (собственного оборудования на объекте нет). Если адрес обязателен — юридический/фактический адрес клиента |
| Количество линий / каналов | Сколько одновременных разговоров нужно (обычно 2–10) |
| Абонентские устройства (если спрашивают) | Софтфоны: приложение Битрикс24 (веб, ПК, мобильное); при наличии — IP-телефоны (модель) |

Одной строкой, если поле одно:
> Облачная IP-АТС «Битрикс24» (1С-Битрикс), программная АТС, подключение по SIP (SIP-trunk с регистрацией).

Оператору для заявки этого достаточно: поле нужно для учёта, куда терминируется линия.
Если менеджер сомневается — скажите, что это «виртуальная АТС / облачная АТС, подключение
по SIP-trunk с регистрацией»; операторы такие заявки принимают постоянно.

## Что сразу попросить у оператора (для настройки в Б24)

- **SIP-trunk с аутентификацией по логину/паролю (регистрация)**, а не по IP.
  У облака Битрикс24 нет фиксированного IP, который клиент мог бы дать оператору для whitelist.
- SIP-сервер (домен/IP) и порт, логин, пароль, при необходимости — outbound proxy / auth user.
- Транспорт UDP (или TCP), кодеки G.711 (PCMA/PCMU).
- Какой номер передаётся в CallerID на исходящих, формат номера (с +7 / 8 / без).
- Нужно ли отдельно разрешать международные/междугородние направления.

## Настройка в Битрикс24

Телефония → Подключение → SIP-коннектор (нужна оплаченная лицензия SIP-коннектора) →
**«Облачная АТС»** → вписать сервер, логин, пароль от оператора → сохранить и проверить
статус регистрации. Затем настроить линию: маршрутизацию входящих, очередь, CallerID.

Как потом найти номер линии — см. `sip-connector-find-number.md`.
