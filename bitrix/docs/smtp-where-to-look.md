# Где посмотреть SMTP в Битрикс24 (то, что не видно обычному пользователю)

В Битриксе два разных SMTP — не путать:
1. **SMTP портала** — через него уходят системные письма: приглашения, уведомления,
   восстановление пароля, письма из бизнес-процессов и почтовых событий.
2. **SMTP почтового ящика или отправителя** — через него уходят письма сотрудника из
   «Почты» и из CRM.

## Коробка: SMTP портала (только админ / доступ к серверу)
- **BitrixVM**: меню виртуальной машины → управление сайтами → настройка почты для сайта.
  Там задаётся SMTP-сервер, порт, логин, TLS. На самом сервере это конфиг msmtp:
  `/etc/msmtprc` или `~bitrix/.msmtprc`. В файле лежит пароль — не копировать в чаты.
- **Файл `/bitrix/.settings.php`**, секция `smtp` (в новых версиях главного модуля):
  включён ли SMTP, логирование (`debug`, `log_file`).
- **`/bitrix/php_interface/init.php`**: если там переопределена функция `custom_mail`,
  почта уходит не так, как настроено выше.
- **Админка**: Настройки → Настройки продукта → Настройки модулей → Главный модуль —
  адрес отправителя по умолчанию и почтовые параметры. Очередь писем: Настройки →
  Почтовые и СМС события (шаблоны и события). Названия пунктов зависят от версии.
- Проверить отправку: Настройки → Инструменты → Проверка системы — там есть тест
  отправки почты.

## Облако
SMTP портала нет: системные письма уходят через серверы Битрикс24.

## Ящик или отправитель (облако и коробка)
- **Почта** → шестерёнка у ящика → Настройки ящика → блок отправки через внешний SMTP.
  Видит владелец ящика и те, кому выдан доступ к ящику.
- **CRM**: в форме письма поле «От кого» → настройка отправителей. Там SMTP для
  конкретного адреса.
