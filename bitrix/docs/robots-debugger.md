# Отладчик роботов — проверка автоматизации после настройки

Нативный инструмент Битрикс24 для теста роботов и триггеров в сделках.

## Где находится
CRM → Сделки → **Роботы** (настройка роботов воронки) → кнопка **«Отладчик»** вверху окна роботов.
Название/место кнопки может немного отличаться по версиям интерфейса — не сверено на живом портале.

## Два режима
- **Тестовая сделка** — отладчик сам создаёт тестовую сделку, можно двигать её по стадиям и смотреть, какие роботы сработали и выполнились ли условия.
- **Реальная сделка** — выбрать существующую сделку и проверить на ней.

## Что видно
- слева — стадии и роботы на каждой;
- справа — значения выбранных полей и лог: что сработало, какие условия выполнены, ошибки.

## Чего отладчик не проверяет
Одной кнопки «проверить весь портал» нет. Отдельно проверить вручную:
- телефония: тестовый входящий и исходящий звонок с каждого рабочего места;
- WhatsApp/открытые линии: сообщение с постороннего номера → появилась сделка → ответ дошёл;
- права: зайти под менеджером (или проверить роль) — видит только своё.
