# Авторизационные данные сотрудников в Битрикс24

**Пароли сотрудников посмотреть нельзя** — ни администратору, ни поддержке: Битрикс24 хранит их только в виде хэша (облако — через Битрикс24 ID).

## Что администратор может посмотреть / сделать
| Что | Где |
|---|---|
| Логин (e-mail или телефон) | Сотрудники → карточка сотрудника → контакты |
| История входов: дата, IP, устройство, браузер | Настройки → Безопасность → **История входов** (платные тарифы — у бесплатных значок замка) |
| Активные сессии, «выйти на всех устройствах» | Карточка сотрудника → Безопасность / свой профиль → Безопасность |
| Сбросить доступ | Сотрудник сам: «Забыли пароль?» на странице входа. Админ: карточка → «Действия» → повторно пригласить / уволить и пригласить заново, либо попросить сменить пароль |
| Отключить доступ | Карточка → «Действия» → «Уволить» (вход блокируется, данные остаются) |
| Двухфакторная авторизация | Настройки → Безопасность → обязательная 2FA для всех/групп |

## Коробка
Админ-панель → Настройки → Пользователи → Список → пользователь: логин виден, пароль — нет, но админ может **задать новый пароль**. Журнал входов — Настройки → Инструменты → Журнал событий (если включено логирование входов).

Названия пунктов не сверены на живом портале.
