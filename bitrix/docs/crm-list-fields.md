# CRM, режим «Список»: где настраиваются и редактируются поля

## Какие колонки видны в списке
CRM → Сделки → «Список» → шестерёнка (⚙️) в левом верхнем углу таблицы →
отметить нужные поля. Настройка личная; администратор может нажать
«Применить для всех», чтобы вид был у всех сотрудников.

## Изменить значения прямо в списке
Отметить галочками одну или несколько сделок → в нижней панели «Редактировать» →
ячейки становятся редактируемыми → «Сохранить». Так удобно массово менять
ответственного, стадию и т.п.

## Создать новое поле или изменить существующее
Сам список поля не создаёт — поля общие для сделки:
- быстрее всего из карточки сделки: раздел «О сделке» → «Создать поле»
  (или «Настроить» → изменить существующее);
- полный перечень: настройки CRM → «Пользовательские поля» → «Сделка».
Новое поле потом включить в списке через шестерёнку.

Нужны права администратора CRM. Названия пунктов могут отличаться по версиям.
