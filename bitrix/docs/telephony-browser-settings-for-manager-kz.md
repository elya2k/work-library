# Менеджерге нұсқаулық (қазақша): Битрикс24 қоңыраулары үшін браузер баптаулары

Орысша нұсқасы және қашан жіберу керегі: `telephony-browser-settings-for-manager.md`.
Мәзір атаулары орысша қалдырылды, себебі Chrome мен Windows әдетте орыс тілінде тұрады.

---

Битрикс24 қоңыраулары келіп тұруы үшін Chrome баптауларын ретімен тексеріңіз. 5 минуттай уақыт алады

1. Битрикс24-ті ашыңыз. Сайт адресінің сол жағындағы құлып немесе жүгірткі белгішесін басып, Настройки сайтов бөлімін таңдаңыз. Микрофон, Уведомления және Звук үшін Разрешить қойыңыз. Егер дыбыста Без звука тұрса, қоңырау келеді, бірақ шылдырламайды

2. Адрес жолына chrome://settings/performance енгізіп, Enter басыңыз. Экономия памяти мен Энергосбережение функцияларын өшіріңіз. Өшіргіңіз келмесе, төмендегі Всегда держать эти сайты активными бөлімінде Добавить батырмасын басып, Битрикс24 адресін қойыңыз

3. Битрикс24 бір ғана вкладкада ашық тұруы керек және оны жұмыс күні бойы жаппаңыз. Браузерді жиыруға болады. Егер компьютерде Битрикс24 қосымшасы бар болса, екеуінің біреуін ғана ашық ұстаңыз

4. Битрикс24 вкладкасын тінтуірдің оң жақ батырмасымен басыңыз. Онда Включить звук на сайте деген пункт болса, соны басыңыз

5. Браузерде AdBlock, uBlock немесе VPN орнатылған болса, Битрикс24 үшін оларды өшіріңіз

6. Windows-та Пуск, одан кейін Параметры, Система, Уведомления ашыңыз. Хабарландырулар қосулы болуы керек, Google Chrome үшін де. Не беспокоить режимін өшіріңіз

7. Адрес жолына chrome://settings/content/microphone енгізіп, жоғарыдан өз гарнитураңызды таңдаңыз. Windows-тағы дыбыс та гарнитураға шығуы керек, оны төменгі оң жақтағы динамик белгішесінен көруге болады

8. https://echo.voximplant.com/iframe_ru.html ашып, Start басып, бірдеңе айтыңыз. Өз дауысыңызды естісеңіз, бәрі жұмыс істеп тұр. Содан кейін әріптесіңізден Битрикс24 арқылы сізге қоңырау шалуын сұраңыз

Қоңырау бәрібір келмесе, қай уақытта қоңырау шалғанын жазып, бірінші пункттегі скриншотты жіберіңіз
